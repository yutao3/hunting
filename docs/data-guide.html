Data, interpretation & limitations

Demonstration data are artificial. No actual Sentinel-2 analytics, wildlife observations or validated habitat models are included in this first prototype. Sample polygons, dates and heatmaps exist purely to test the website and data interfaces.

How to interpret the layers

Heatmap: a georeferenced, pre-rendered coloured image of an arbitrary model index between 0 and 100. It is not an animal encounter probability.

Habitat polygons: WGS84 GeoJSON regions with a numeric score and optional attributes. The score slider filters these areas only; raster values are unchanged.

Landscape changes: a separate class of polygons, shown orange. Real versions could represent forest clearing, crop harvest and related changes after independent EO processing.

Publishing your own outputs

Read README.md and docs/SCHEMA.md in the GitHub repository. New products need no change to the map code: add files and update data/catalog.json.

Provenance and compliance

Publish acquisition dates, processing dates, model version, sensor inputs, resolution, validation status and licences alongside each production data layer. Do not disclose protected wildlife positions, personal camera detections or private hunting-ground boundaries through a public GitHub Pages site.
